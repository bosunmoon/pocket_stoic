# Pocket Stoic

A local Retrieval-Augmented Generation (RAG) system built on Stoic texts:
- Meditations
- Enchiridion
- Discourses

## Features
- FAISS vector search
- Hybrid lexical + semantic scoring
- FastAPI backend
- Designed for local LLM integration

## Stack
- Python
- FAISS
- bge-small-en-v1.5 embeddings
- FastAPI

## Roadmap
- Query re-ranking
- Local LLM integration
- Mobile app version
